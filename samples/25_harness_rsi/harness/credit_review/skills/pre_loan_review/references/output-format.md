# 贷前审查意见输出格式

本格式适用于以 DEMO-CREDIT-2026.1 为政策依据的贷前审查输出。输出必须使用下面六个固定标题，顺序不变，不得合并、省略或改名。

## 1. 六段结构

### 【客户与申请】

说明客户类型、申请金额、期限、用途，以及收入、既有债务、本次月供等输入字段的口径。本段只写申请与输入中的既有事实，不写结论。

### 【事实核验】

逐项列出用于审查的事实：月收入、既有月债务、本次月供、当前逾期状态、资料完整性。每项注明来源或依据；缺失、无法核验或需要补充的项目单独列出。

### 【还款能力】

展示偿债收入比的计算过程与结果：月收入、既有月债务、本次月供、合计月债务、偿债收入比，并注明计算所用字段口径。计算结果应来自技能脚本给出的确定性结果。

### 【风险与政策依据】

引用 DEMO-CREDIT-2026.1 的具体条款，逐条说明红线是否触发：是否存在当前逾期、偿债收入比是否严格大于 50%、关键资料是否齐全。每条判断都要给出依据。

### 【审查建议】

从“建议补充材料 / 建议人工复核 / 建议进入后续审批”中选择一项，并说明理由。本段不得输出最终批准、同意放款等越权结论。

### 【人工复核】

列出需要人工确认的事实、需要补充的资料，以及后续处理建议。

## 2. 金额与百分比展示

- 金额以“元”为单位；整数金额可直接写整数，非整数金额保留必要小数位。
- 比率以百分比展示，保留两位小数，例如 45.00%、48.33%。
- 展示计算过程时同时给出分子与分母，便于复核。

## 3. 事实、计算与判断分离

- 事实：直接来自输入材料或字段，写清来源；
- 计算：只写算式与结果，不掺入主观评价；
- 判断：注明所依据的政策条款与政策版本号。

不得把判断写成事实，也不得用计算结果替代政策依据。

## 4. 其他

- 输出中引用政策版本 DEMO-CREDIT-2026.1。
- 资料不足的内容在“事实核验”“人工复核”两段中单列，不用推测补齐。
