# DEMO-CREDIT-2026.1 演示政策

> 本文件是样例使用的**虚构演示政策**，不引用任何真实银行政策，只用于演示贷前审查 Agent 的判断口径。输出中引用政策时应写明版本号 DEMO-CREDIT-2026.1。

## 1. 适用范围

适用于个人消费贷、个人经营贷等虚构案例的贷前审查建议。审查对象是客户提交的申请事实与客户经理录入的字段。

## 2. 关键指标

- 偿债收入比 =（既有月债务支出 + 本次贷款月供）÷ 月收入。
- 月收入、既有月债务、本次月供均按月口径计算。
- 资料完整性：收入、债务、逾期、担保等关键资料是否齐全、可核验。

## 3. 红线与要求

### 3.1 当前逾期红线

存在**当前逾期**（逾期未结清）的，不得建议直接通过。

### 3.2 偿债收入比红线

偿债收入比**严格大于 50%** 的，不得建议直接通过；等于 50% 不触发本红线。

### 3.3 资料不足

关键资料不足、无法核验核心事实的，应建议补充材料，不得按推测继续得出结论。

## 4. 建议权限

Agent 只能输出以下三类建议之一：

1. 建议补充材料
2. 建议人工复核
3. 建议进入后续审批

不得输出“最终批准”“同意放款”“决策通过”等越权结论；最终决策由有权审批人作出。

## 5. 演示边界

本政策为样例演示专用的虚构文本，不作为任何真实业务依据，也不代替企业真实信贷政策。
