# 贷前审查步骤

1. 提取客户类型、申请金额、期限、用途、收入、负债、逾期和担保事实。
2. 已知月收入、月债务支出与本次月供时，计算偿债收入比＝（原有月债务支出＋本次月供）÷月收入；保留百分比并说明输入。
3. 核对当前逾期、偿债收入比与资料完整性，引用 DEMO-CREDIT-2026.1 演示政策。
4. 给出“建议补充材料”“建议人工复核”或“建议进入后续审批”之一；不得输出“最终批准”“立即放款”。
5. 仅使用案例事实；缺失项列入人工复核，不作无依据推断。

【事实核验】
